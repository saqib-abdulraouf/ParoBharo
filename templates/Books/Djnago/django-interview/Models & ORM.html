Models & Database ORM

Q05
ForeignKey aur ManyToManyField mein farq?
Relationships

• ForeignKey: One-to-Many relationship create karta hai (e.g. Ek Category ke multiple Tasks ho sakte hain).
• ManyToManyField: Many-to-Many relationship create karta hai (e.g. Ek Task ke multiple Tags ho sakte hain, aur ek Tag multiple Tasks par apply ho sakta hai).

📌 Real Project Application: In Task Manager, we defined category = models.ForeignKey(Category) and tags = models.ManyToManyField(Tag).
Q06
on_delete=CASCADE ka kya matlab hai?
Integrity

on_delete=CASCADE ensure karta hai ke jab parent model instance (e.g. Category) delete hoga, to us par dependent tamam child model instances (e.g. Tasks) automatically database se remove ho jayenge to prevent orphan data.

📌 Real Project Application: Deleting a Category automatically cascades and purges all associated Tasks belonging to that category.
Q07
select_related aur prefetch_related mein kya farq hai?
Optimization

Dono database query performance optimization ke liye use hote hain (N+1 query problem resolve karne ke liye):

• select_related: SQL JOIN perform karta hai (Single-valued relationships jaise ForeignKey & OneToOne).
• prefetch_related: Alag SQL queries run karke Python layer par relationships join karta hai (Multi-valued relationships jaise ManyToMany & Reverse FKs).

📌 Real Project Application: Using Task.objects.select_related('category').prefetch_related('tags') reduced page query count from 25+ SQL queries down to just 2 queries.
Q08
__str__ method model mein kyun define karte hain?
Representation

__str__ method Model instance ki human-readable string representation return karta hai. Is ke bina Django Admin Panel aur Python Shell mein objects generic output jaise <Task object (1)> display karte hain.

📌 Real Project Application: Defining def __str__(self): return self.title displays the actual task title directly in the Django Admin interface.
