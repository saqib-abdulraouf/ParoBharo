Views & Forms

Q09
FBV (Function-Based Views) aur CBV (Class-Based Views) mein farq?
Views

• FBV: Simple, explicit, and easy to read for custom or small logic.
• CBV: Object-Oriented, reusable, DRY (Don't Repeat Yourself) principle follow karta hai, aur generic features (jaise ListView, CreateView) leverage karta hai. Standard CRUD operations ke liye CBVs prefer kiye jatay hain.

📌 Real Project Application: Used TaskListView(ListView) and TaskCreateView(CreateView) in Task Manager to reduce view boilerplate to under 5 lines per view.
Q10
get_object_or_404 kyun use karte hain?
Error Handling

Agar requested object database mein exist na ho, to ye shortcut function unhandled server exception (DoesNotExist 500 error) throw karne ke bajaye clean HTTP 404 Not Found response render karta hai.

📌 Real Project Application: Fetching a task via task = get_object_or_404(Task, pk=pk) returns an official 404 page if an invalid ID is passed in the URL.
Q11
Form aur ModelForm mein kya farq hai?
Forms

• forms.Form: Standard form jismein input fields manually define kiye jatay hain (e.g. Contact Form, Search Form).
• forms.ModelForm: Direct Model schema se inspect karke automatically form fields generate karta hai aur built-in save() method provide karta hai.

📌 Real Project Application: Defined class TaskForm(forms.ModelForm) with Meta: model = Task to automatically map form submissions directly to the database.

{% csrf_token %} tag template mein kyun zaroori hai?
{% endverbatim %} Security

Ye tag CSRF (Cross-Site Request Forgery) protection token generate karta hai. Is ke zariye Django verify karta hai ke POST/PUT form submissions legitimate app site se aayi hain, kisi malicious third-party site se nahi.

{% verbatim %} 📌 Real Project Application: Every task creation form embeds {% csrf_token %} inside the <form method="POST"> element to pass security checks. {% endverbatim %}
