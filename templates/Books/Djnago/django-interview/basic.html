Basic Concepts & Architecture

Q01
Django kya hai aur ye kis liye use hota hai?
Framework

Django ek high-level Python web framework hai jo rapid development aur clean, pragmatic design follow karta hai. Isko "Batteries-included" bola jata hai kyunke isme Authentication, Admin Panel, ORM, aur Security utilities built-in milti hain.

📌 Real Project Application: In our Task Manager application, Django allowed us to utilize built-in authentication, ORM for database tables, and the admin interface without writing custom boilerplate.
Q02
MVT pattern kya hai? MVC se kaise different hai?
Architecture

Django MVT (Model-View-Template) architecture pattern use karta hai:

• Model: Database layer (tables & schemas)
• View: Business logic layer (MVC ke Controller jaisa)
• Template: Presentation layer (HTML files)

MVC ke Controller ka kaam Django mein framework khud URL routing engine ke zariye handle karta hai.

📌 Real Project Application: In Task Manager, database schemas reside in models.py, application logic in views.py, and UI render logic in templates/.
Q03
makemigrations aur migrate mein kya farq hai?
Database

• makemigrations: Models mein hone wali updates ka Python blueprint (migration file) generate karta hai.
• migrate: Un migration blueprints ko execute karke actual database (e.g. SQLite / PostgreSQL) pe schema changes apply karta hai.

📌 Real Project Application: When adding a new field to the Task model, running makemigrations generated the migration file, and migrate created the database column.
Q04
Django ORM kya hai aur iska kya fayda hai?
ORM

ORM (Object-Relational Mapping) ek abstraction layer hai jo Python objects ko database tables ke sath communicate karne ki permission deti hai. Iska faida ye hai ke developers ko raw SQL queries nahi likhni parhti.

📌 Real Project Application: Fetching all user tasks via Task.objects.filter(user=request.user) instead of writing custom SQL SELECT * FROM task WHERE user_id = ... queries.
