Authentication & Security

Q13
LoginRequiredMixin kya karta hai?
Authorization

LoginRequiredMixin Class-Based Views ko protect karne ke liye use hota hai. Agar unauthenticated user us view ko access karne ki koshish kare to ye automatic login URL par redirect kar deta hai.

📌 Real Project Application: In Task Manager: class TaskListView(LoginRequiredMixin, ListView) ensures guest users cannot access task pages without logging in first.
Q14
Django user passwords ko kaise store karta hai?
Security

Django plain-text passwords kabhi store nahi karta. Default setting mein Django PBKDF2 with SHA-256 password hashing algorithm and cryptographic salt use karta hai. Is se database leak hone ki surat mein bhi passwords recover nahi kiye ja sakte.

📌 Real Project Application: User passwords in our database look like pbkdf2_sha256$260000$saltsalt$hashhash... instead of raw strings.
Q15
UserCreationForm kya provide karta hai?
User Auth

UserCreationForm Django ka built-in ModelForm hai jo user registration handle karta hai. Ye Username, Password, aur Password Confirmation fields, password strength validation, aur user saving out-of-the-box manage karta hai.

📌 Real Project Application: Used form = UserCreationForm(request.POST) in signup view to register new users with built-in password validation.
Q16
Sirf current logged-in user ka data Views mein kaise filter karte hain?
Data Isolation

Class-Based View mein get_queryset() method ko override karke current request user par filter lagatay hain:
return Task.objects.filter(user=self.request.user)

📌 Real Project Application: Overriding get_queryset() in TaskListView guarantees each authenticated user only sees their own tasks.
