Virtual Environment + Django Installation

Step-by-step guide to set up your Django development environment

1 Virtual Environment Banana

Har Django project ke liye alag virtual environment banana best practice hai (taake projects ke packages mix na hon). Apna terminal/CMD kholein aur ye commands chalayein:

Terminal / Command Prompt 
# Ek folder banayein apne project ke liye
mkdir django_projects
cd django_projects

# Virtual environment banayein
python -m venv venv

# Activate karein
# Windows pe:
venv\Scripts\activate

# Mac/Linux pe:
source venv/bin/activate
Tip: Activate hone ke baad terminal ke start mein (venv) likha nazar aayega — iska matlab hai ye successfully ho gaya.

2 Django Install Karna

$ pip install django

Install hone ke baad check karein version:

$ django-admin --version

! Common Error & Fix

Fatal Error

Fatal error in launcher: Unable to create process using "...": The system cannot find the file specified.

Diagnosis: Ye error isliye aa raha hai kyunke aapka virtual environment pehle kisi aur location pe bana tha, phir aapne folder move/rename kar diya. Venv ke andar paths hardcoded hoti hain, isliye jab folder move hota hai to venv toot jaata hai.

Fix simple hai — purana venv delete karke, sahi jagah se naya banayein.

✅ Expected Result

✅ (practice) terminal ke shuru mein nazar aana chahiye activate hone ke baad.
✅ Django successfully installed with version number.
