Upload your project to GitHub with a professional README — portfolio-ready!

🎉 Bahut khoob! Ab app professional dikh rahi hai. Chaliye aakhri step — GitHub pe upload aur deployment (live link banane) ka process karte hain.

Part 5: GitHub Pe Upload Karna

1 .gitignore File Banayein

Root folder mein .gitignore naam ki file banayein (kuch files GitHub pe nahi jaani chahiye):

.gitignore 
# Virtual Environment
venv/
practice/
env/
.env

# Python Cache
__pycache__/
*.pyc
*.pyo
*.pyd
.Python

# Database
db.sqlite3
*.db

# IDE
.idea/
.vscode/
*.swp
*.swo

# Environment Variables
.env
.env.local

# Logs
*.log
logs/

# Static Files (collected)
staticfiles/
static/

# Media Files
media/

# OS
.DS_Store
Thumbs.db
Why .gitignore? Yeh files GitHub pe nahi jayengi — ✅ Security + Clean repo!

Important: .env file mein SECRET_KEY aur sensitive data hota hai — is liye isko never commit karein!

2 requirements.txt Banayein

Ye file batati hai project ko kaun se packages chahiye — taake koi aur (ya recruiter) aasani se project run kar sake:

$ pip freeze > requirements.txt
requirements.txt (Example) 
Django==4.2.7
gunicorn==21.2.0
whitenoise==6.6.0
dj-database-url==2.1.0
psycopg2-binary==2.9.9
python-decouple==3.8

3 Git Setup Aur Push Karein

$ git init
$ git add .
$ git commit -m "Task Manager - Django CRUD project"
Next: GitHub.com pe jake ek naya repository banayein (bina README/gitignore initialize kiye), aur wo commands copy karein jo GitHub khud dikhata hai:
GitHub Commands 
git remote add origin https://github.com/aapka-username/task-manager.git
git branch -M main
git push -u origin main

4 Achi README Likhein

README.md mein ye include karein:

README.md — Professional Template 
# Task Manager

A complete Django CRUD application with user authentication, categories, and tags.

## 🚀 Features

- ✅ **Full CRUD** — Create, Read, Update, Delete tasks
- ✅ **User Authentication** — Signup, Login, Logout
- ✅ **User-Specific Data** — Each user sees only their own tasks
- ✅ **Categories** — Organize tasks by category
- ✅ **Tags** — Add multiple tags to tasks
- ✅ **Admin Panel** — Customized with search, filters, and editable fields
- ✅ **Responsive Design** — Bootstrap 5 styling
- ✅ **Deployed** — Live on Render.com

## 🛠️ Tech Stack

- **Backend:** Django 4.2
- **Database:** SQLite (dev) / PostgreSQL (prod)
- **Frontend:** Bootstrap 5
- **Deployment:** Render.com
- **Version Control:** Git & GitHub

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/your-username/task-manager.git
cd task-manager

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Apply migrations
python manage.py migrate

# Create superuser (optional)
python manage.py createsuperuser

# Run development server
python manage.py runserver
```
