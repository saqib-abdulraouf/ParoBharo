Models banana, migrations

The heart of Django — database tables as Python classes

Ab hum Django ke sabse important part pe aate hain — Models. Yahan se real CRUD development shuru hoti hai.

Models Kya Hain?

Definition: Model ek Python class hoti hai jo database table ko represent karti hai. Har class attribute ek column banta hai.

Django ORM (Object-Relational Mapping) hume SQL likhne ki zaroorat nahi deta — hum Python code se database handle karte hain.

15 Task Model Banayein

tasks/models.py file kholein aur ye code likhein:

tasks/models.py
from django.db import models

class Task(models.Model):
    title = models.CharField(max_length=200)
    description = models.TextField(blank=True)
    completed = models.BooleanField(default=False)
    created_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.title

Har Line Samjhein:

Field Type Description
title CharField(max_length=200) Chhoti text (title ke liye), max_length zaroori hai
description TextField(blank=True) Lambi text (description ke liye), blank=True matlab ye field khali chhoda ja sakta hai
completed BooleanField(default=False) True/False value (default False rakha hai)
created_at DateTimeField(auto_now_add=True) Jab task banega, uska time automatically save ho jayega
__str__ return self.title Django admin panel mein task ka naam readable dikhane ke liye (warna "Task object (1)" jaisa ajeeb dikhta hai)

16 Migration Banayein

Model banane ka matlab ye nahi ke database mein table ban gayi — Django ko batana padta hai "migrate" karke:

$ python manage.py makemigrations
Samjhein: Ye command ek migration file banayegi (jaise blueprint) jo batati hai database mein kya changes karne hain.

17 Migration Apply Karein

$ python manage.py migrate
Result: Ye actual database (SQLite, jo Django default use karta hai) mein table create karega.
Practice Checklist

✅ Step 1: tasks/models.py mein Task model likha?
✅ Step 2: python manage.py makemigrations chalaya?
✅ Step 3: python manage.py migrate chalaya?
