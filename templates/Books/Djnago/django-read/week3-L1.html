Function-Based Views: Task List and Task Create

CRUD Kya Banayenge?

Hum apna khud ka frontend banayenge (admin panel ke bagair) jahan koi bhi user:

➕ Create Naya task add kar sake
📋 Read Saare tasks ki list dekh sake
✏️ Update Task edit kar sake
🔍 Read (Detail) Ek task ka detail dekh sake
🗑️ Delete Task delete kar sake
Approach: Hum ye Function-Based Views (FBVs) se start karenge (samajhna aasan hai), phir baad mein Class-Based Views (CBVs) bhi seekhenge (jo jobs mein zyada pucha jata hai).

1 READ — Saare Tasks Ki List Dikhana

tasks/views.py ko update karein:

tasks/views.py 
from django.shortcuts import render, redirect, get_object_or_404
from .models import Task

def task_list(request):
    tasks = Task.objects.all()
    return render(request, 'tasks/task_list.html', {'tasks': tasks})
Task.objects.all() Database se saare tasks nikaalna
{'tasks': tasks} Template ko context bhejna — ye dictionary hai

2 Template Banayein

tasks/templates/tasks/task_list.html:

tasks/templates/tasks/task_list.html 
<!DOCTYPE html>
<html>
<head>
    <title>Task List</title>
</head>
<body>
    <h1>My Tasks</h1>

    <ul>
        {% for task in tasks %}
            <li>
                {{ task.title }} 
                {% if task.completed %}✅{% else %}⏳{% endif %}
            </li>
        {% empty %}
            <li>Koi task nahi hai.</li>
        {% endfor %}
    </ul>
</body>
</html>

Django Template Language (DTL) — Samjhein:

{% for task in tasks %} Python loop jaisa, lekin template mein
{{ task.title }} Variable print karna (double curly braces)
{% if %} Condition check karna
{% empty %} Agar list khali ho to ye dikhega

4 CREATE — Naya Task Add Karne Ka Form

Approach: Hum Django Forms use karenge (manually HTML form bhi likh sakte hain, lekin ModelForm zyada powerful aur kam code wala tareeqa hai).

Step 1: Forms File Banayein

tasks app ke andar ek nayi file banayein: tasks/forms.py

tasks/forms.py 
from django import forms
from .models import Task

class TaskForm(forms.ModelForm):
    class Meta:
        model = Task
        fields = ['title', 'description', 'category', 'tags', 'completed']
ModelForm Khud-ba-khud model ke fields se form bana leta hai
Meta class Batati hai konsa model use karna hai aur konse fields form mein chahiye

Step 2: Create View Banayein

tasks/views.py mein add karein:

tasks/views.py 
from django.shortcuts import render, redirect, get_object_or_404
from .models import Task
from .forms import TaskForm

def task_list(request):
    tasks = Task.objects.all()
    return render(request, 'tasks/task_list.html', {'tasks': tasks})


def task_create(request):
    if request.method == 'POST':
        form = TaskForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect('task_list')
    else:
        form = TaskForm()
    return render(request, 'tasks/task_form.html', {'form': form})

Line by Line Samjhein:

request.method == 'POST' User ne form submit kiya hai (data bheja hai)
TaskForm(request.POST) Submitted data se form banaya
form.is_valid() Django khud check karta hai data sahi hai ya nahi (required fields, data types waghera)
form.save() Valid hone par database mein save ho jata hai
redirect('task_list') Save hone ke baad list page pe wapas bhej dena (refresh karne pe dobara submit nahi hoga)
else Jab user pehli baar page open kare (GET request), khali form dikhana

Step 3: Template Banayein

tasks/templates/tasks/task_form.html:

tasks/templates/tasks/task_form.html 
<!DOCTYPE html>
<html>
<head>
    <title>Add Task</title>
</head>
<body>
    <h1>Add New Task</h1>

    <form method="POST">
        {% csrf_token %}
        {{ form.as_p }}
        <button type="submit">Save</button>
    </form>

    <a href="{% url 'task_list' %}">Back to list</a>
</body>
</html>

Samjhein:

{% csrf_token %} Zaroori hai! Django security ke liye ye token maangta hai warna form submit hi nahi hoga
{{ form.as_p }} Pora form <p> tags mein automatically render kar deta hai
{% url 'task_list' %} URL ka naam use kar ke link banana (hardcode karne se behtar hai)

Step 4: URL Add Karein

tasks/urls.py 
from django.urls import path
from . import views

urlpatterns = [
    path('', views.task_list, name='task_list'),
    path('create/', views.task_create, name='task_create'),
]

Step 5: List Page Se Link Karein

task_list.html mein <h1> ke neeche ye add karein:

tasks/templates/tasks/task_list.html 
<a href="{% url 'task_create' %}">+ Add New Task</a>
