Full CRUD — Update & Delete

Function-Based Views: Task Update and Task Delete
{% verbatim %}
Bohat khoob! Ab Update aur Delete — dono ek sath karte hain kyunke pattern Create jaisa hi hai.

1 Update — Existing Task Edit Karna

Step 1: View Banayein

tasks/views.py mein add karein:

tasks/views.py 
def task_update(request, pk):
    task = get_object_or_404(Task, pk=pk)
    if request.method == 'POST':
        form = TaskForm(request.POST, instance=task)
        if form.is_valid():
            form.save()
            return redirect('task_list')
    else:
        form = TaskForm(instance=task)
    return render(request, 'tasks/task_form.html', {'form': form})

Samjhein:

pk "Primary Key" — yani task ki ID jo URL se aayegi
get_object_or_404(Task, pk=pk) us ID ka task dhundo, agar na mile to 404 error page dikhao (crash nahi hoga)
instance=task 👈 Sabse important hai! Ye Django ko batata hai "naya task nahi banana, isi purane task ko update karna hai". Bina is ke Django naya record bana dega.
task_form.html Wahi template use kiya — kyunke form same hai, sirf data pehle se filled hoga
Pro Tip: instance=task ke baghair Django naya record create karega — ye ek common mistake hai!

2 Delete — Task Hataana

Step 1: Delete View

tasks/views.py 
def task_delete(request, pk):
    task = get_object_or_404(Task, pk=pk)
    if request.method == 'POST':
        task.delete()
        return redirect('task_list')
    return render(request, 'tasks/task_confirm_delete.html', {'task': task})
if request.method == 'POST' Sirf POST request pe actual delete ho ga
task.delete() Database se task delete kar do
task_confirm_delete.html Pehle confirmation page dikhate hain (accidental delete se bachne ke liye)
Security: Delete direct nahi kar dete — pehle confirmation page dikhate hain. Sirf POST request pe hi actual delete hota hai (GET request pe nahi!).

Step 2: Delete Confirmation Template

tasks/templates/tasks/task_confirm_delete.html:

tasks/templates/tasks/task_confirm_delete.html

    </form>

</html>

3 URLs Add Karein

tasks/urls.py:

tasks/urls.py 
from django.urls import path
from . import views

urlpatterns = [
    path('', views.task_list, name='task_list'),
    path('create/', views.task_create, name='task_create'),
    path('<int:pk>/update/', views.task_update, name='task_update'),
    path('<int:pk>/delete/', views.task_delete, name='task_delete'),
]
<int:pk> URL se ek integer capture karega aur view ko pk naam se bhejega (jaise /1/update/ → pk=1)

5 Complete views.py

Yeh raha complete tasks/views.py — CRUD ke saare functions ek jagah:

tasks/views.py (Complete) 
from django.shortcuts import render, redirect, get_object_or_404
from .models import Task
from .forms import TaskForm

# READ — All Tasks
def task_list(request):
    tasks = Task.objects.all()
    return render(request, 'tasks/task_list.html', {'tasks': tasks})

# CREATE — New Task
def task_create(request):
    if request.method == 'POST':
        form = TaskForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect('task_list')
    else:
        form = TaskForm()
    return render(request, 'tasks/task_form.html', {'form': form})

# UPDATE — Edit Existing Task
def task_update(request, pk):
    task = get_object_or_404(Task, pk=pk)
    if request.method == 'POST':
        form = TaskForm(request.POST, instance=task)
        if form.is_valid():
            form.save()
            return redirect('task_list')
    else:
        form = TaskForm(instance=task)
    return render(request, 'tasks/task_form.html', {'form': form})

# DELETE — Remove Task
def task_delete(request, pk):
    task = get_object_or_404(Task, pk=pk)
    if request.method == 'POST':
        task.delete()
        return redirect('task_list')
    return render(request, 'tasks/task_confirm_delete.html', {'task': task})
Practice Checklist
  • task_update view banaya (with instance=task)
  • task_delete view banaya
  • task_confirm_delete.html template banaya
  • update/ aur delete/ URLs add kiye
  • List page mein Edit aur Delete links add kiye
