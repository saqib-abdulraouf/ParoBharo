Django App Creation + Registration

Learn the difference between Project & App, create your first app

Project vs App — Farq Samjhein

Project (config)
Poori website ka container — settings, URLs, aur overall configuration sambhalta hai.
config/
App (tasks)
Ek chhota module jo ek specific kaam karta hai (jaise "blog", "users", "tasks"). Ek project mein multiple apps ho sakti hain.
tasks/  |  blog/  |  users/
Key Concept: Project = Website ka wrapper (settings, URLs, overall config)
App = Feature module (specific functionality like blog, tasks, users)

config project ka naam hai, aur hum ab ek tasks app banayenge.

5 Pehli App Banayein

Hum ek simple "tasks" app banayenge jo aage chal ke hamara CRUD project banega (Task Manager). Terminal mein:

Terminal / Command Prompt
python manage.py startapp tasks

Ye ek naya folder banayega:

tasks/ ← Naya app folder
migrations/ ← Database migrations
__init__.py
admin.py ← Admin panel registration
apps.py ← App configuration
models.py ← Database tables yahan define hongi
tests.py ← Unit tests
views.py ← Logic yahan likhenge

6 App ko Register Karein

Django ko batana zaroori hai ke ye app use ho rahi hai. config/settings.py file kholein aur INSTALLED_APPS list dhundein:

config/settings.py
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'tasks',   ← ye line add karein
]
Important: App ka naam 'tasks' string mein likhna hai, aur comma (,) lagana mat bhoolna!
