Django ka MVT Flow

MVT = Model · View · Template
Django ka pattern (MVC jaisa, lekin thoda alag). Abhi hum View aur URL seekh rahe hain — Model baad mein aayega (Week 2).

MVT Explained:
View = Python function jo request leta hai aur response wapas bhejta hai.
Template = HTML file jo frontend dikhati hai.
Model = Database structure (aage aayega).

Abhi hum simple HTTP response bhej rahe hain — Hello, Django is working!

7 Pehla View Banayein

tasks/views.py file kholein — abhi khali hogi. Ismein ye code likhein:

tasks/views.py
from django.http import HttpResponse

def home(request):
    return HttpResponse("Hello, Django is working!")
Samjhein: View ek Python function hai jo request leta hai (browser se aane wali call) aur response wapas bhejta hai (jo browser mein dikhta hai).

8 App ke Andar URLs File Banayein

tasks folder ke andar ek nayi file banayein: tasks/urls.py

tasks/urls.py
from django.urls import path
from . import views

urlpatterns = [
    path('', views.home, name='home'),
]
Samjhein: Ye file batati hai ke jab koi specific URL aaye, to konsi view chalani hai.

9 Main Project ke URLs se Connect Karein

config/urls.py file kholein (ye already Django ne bana rakhi thi). Isko is tarah edit karein:

config/urls.py
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('tasks.urls')),
]
Samjhein: config/urls.py main entry point hai — ye batata hai ke agar URL tasks app se related hai to tasks/urls.py ko dekho.
