Part 4: Bootstrap Se Styling

1 Base Template Banayein

Ek common template banayenge jise saari pages use karengi — is se code repeat nahi hoga (DRY principle).

templates/base.html (root templates folder mein):

templates/base.html 
<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}Task Manager{% endblock %}</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <nav class="navbar navbar-dark bg-dark">
        <div class="container">
            <a class="navbar-brand" href="{% url 'task_list' %}">Task Manager</a>
            <div>
                {% if user.is_authenticated %}
                    <span class="text-white me-3">Hi, {{ user.username }}</span>
                    <a href="{% url 'logout' %}" class="btn btn-outline-light btn-sm">Logout</a>
                {% else %}
                    <a href="{% url 'login' %}" class="btn btn-outline-light btn-sm me-2">Login</a>
                    <a href="{% url 'signup' %}" class="btn btn-light btn-sm">Signup</a>
                {% endif %}
            </div>
        </div>
    </nav>

    <div class="container mt-4">
        {% block content %}
        {% endblock %}
    </div>
</body>
</html>

Samjhein — Template Inheritance:

{% block title %} Page title ke liye placeholder — child templates fill karengi
{% block content %} Main content ke liye placeholder — child templates fill karengi
{% extends 'base.html' %} Child template mein base template ko extend karna
DRY Principle: Ye Django ka bohat powerful feature hai — navbar/header ek hi jagah likhna padta hai, har page mein nahi!

2 Task List Ko Update Karein

tasks/templates/tasks/task_list.html ko poora replace karein:

tasks/templates/tasks/task_list.html 
{% extends 'base.html' %}

{% block title %}My Tasks{% endblock %}

{% block content %}
    <h1>My Tasks</h1>
    <a href="{% url 'task_create' %}" class="btn btn-primary mb-3">+ Add New Task</a>

    <ul class="list-group">
        {% for task in tasks %}
            <li class="list-group-item d-flex justify-content-between align-items-center">
                <span>
                    {{ task.title }}
                    {% if task.completed %}
                        <span class="badge bg-success">Done</span>
                    {% else %}
                        <span class="badge bg-warning">Pending</span>
                    {% endif %}
                </span>
                <span>
                    <a href="{% url 'task_update' task.pk %}" class="btn btn-sm btn-outline-secondary">Edit</a>
                    <a href="{% url 'task_delete' task.pk %}" class="btn btn-sm btn-outline-danger">Delete</a>
                </span>
            </li>
        {% empty %}
            <li class="list-group-item">Koi task nahi hai.</li>
        {% endfor %}
    </ul>
{% endblock %}

Bootstrap Components Used:

btn btn-primary Primary button — Add New Task
list-group Styled list — tasks ko professional dikhana
badge bg-success Green badge — "Done" status
badge bg-warning Yellow badge — "Pending" status
btn btn-outline-secondary Outline button — Edit
btn btn-outline-danger Red outline button — Delete

3 Baaki Templates Bhi Update Karein

task_form.html

tasks/templates/tasks/task_form.html 
{% extends 'base.html' %}

{% block title %}Task Form{% endblock %}

{% block content %}
    <h1>Task Form</h1>
    <form method="POST">
        {% csrf_token %}
        {{ form.as_p }}
        <button type="submit" class="btn btn-primary">Save</button>
        <a href="{% url 'task_list' %}" class="btn btn-secondary">Cancel</a>
    </form>
{% endblock %}

task_confirm_delete.html

tasks/templates/tasks/task_confirm_delete.html 
{% extends 'base.html' %}

{% block title %}Delete Task{% endblock %}

{% block content %}
    <h1>Delete "{{ task.title }}"?</h1>
    <p>Kya aap sure hain? Ye action wapas nahi ho sakta.</p>
    <form method="POST">
        {% csrf_token %}
        <button type="submit" class="btn btn-danger">Haan, Delete Karein</button>
        <a href="{% url 'task_list' %}" class="btn btn-secondary">Cancel</a>
    </form>
{% endblock %}
