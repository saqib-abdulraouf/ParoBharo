Django Templates

Learn how to render HTML pages instead of plain text

Ab hum agla important concept seekhte hain — Templates. Abhi tak hum plain text bhej rahe the (HttpResponse), lekin real websites HTML dikhati hain. Django mein HTML files ko "templates" kehte hain.

11 Templates Folder Setup Karein

tasks app ke andar ye folder structure banayein:

tasks/
templates/
tasks/
home.html ← Template file
$ mkdir tasks\templates\tasks (Windows)
Note: tasks folder ke andar dobara tasks folder banane ka reason hai — Django templates ko app ke naam se namespace karta hai, taake do alag apps mein same naam ki file ho to conflict na ho.

12 HTML Likhein

tasks/templates/tasks/home.html mein:

tasks/templates/tasks/home.html
<!DOCTYPE html>
<html>
<head>
    <title>Task Manager</title>
</head>
<body>
    <h1>Welcome to Task Manager</h1>
    <p>Django templates working!</p>
</body>
</html>

13 View ko Update Karein (Template Render Karne Ke Liye)

tasks/views.py mein HttpResponse ki jagah render use karenge:

tasks/views.py
from django.shortcuts import render

def home(request):
    return render(request, 'tasks/home.html')
Samjhein: render() function template ko load karta hai, usme context (data) pass karta hai, aur HTML response wapas bhejta hai.

render(request, 'tasks/home.html') — pehla parameter request, doosra template path.

14 Server Dobara Check Karein

$ python manage.py runserver

Browser refresh karein — ab proper HTML page dikhna chahiye ("Welcome to Task Manager" heading ke sath).

Browser mein ye dikhna chahiye:
