Part 6: Deployment (Live Link)

Why Render.com? Free options mein sabse aasan Render.com ya PythonAnywhere hain Django ke liye.
Hum Render.com use karenge — ye free hai, Django ke liye best support deta hai, aur setup seedha hai.

1 Production Ke Liye Zaroori Packages Install Karein

Terminal mein (venv activate hona chahiye):

$ pip install gunicorn whitenoise dj-database-url psycopg2-binary python-decouple

Ye kyun chahiye:

gunicorn Production server — runserver sirf development ke liye hai
whitenoise Static files (CSS/JS) serve karne ke liye bina extra setup ke
dj-database-url Render ka database URL Django ko samjhane ke liye
psycopg2-binary PostgreSQL database ke liye (Render free PostgreSQL deta hai)
python-decouple Secret keys ko code se alag rakhne ke liye (security best practice)

2 settings.py Ko Production-Ready Banayein

config/settings.py mein changes:

config/settings.py 
import os
from decouple import config
import dj_database_url

SECRET_KEY = config('SECRET_KEY', default='django-insecure-abc123')
DEBUG = config('DEBUG', default=False, cast=bool)

ALLOWED_HOSTS = ['.onrender.com', 'localhost', '127.0.0.1']

MIDDLEWARE = [
    'django.middleware.security.SecurityMiddleware',
    'whitenoise.middleware.WhiteNoiseMiddleware',   # ← ye add karein (SecurityMiddleware ke turant baad)
    'django.contrib.sessions.middleware.SessionMiddleware',
    # ... baaki middleware waise hi rehne dein
]

# Static files
STATIC_URL = 'static/'
STATIC_ROOT = BASE_DIR / 'staticfiles'
STATICFILES_STORAGE = 'whitenoise.storage.CompressedManifestStaticFilesStorage'

# Database
DATABASES = {
    'default': dj_database_url.config(
        default=f"sqlite:///{BASE_DIR / 'db.sqlite3'}"
    )
}

Samjhein:

SECRET_KEY aur DEBUG Ab environment variables se aayenge — code mein hardcode nahi honge (security best practice)
ALLOWED_HOSTS Batata hai konse domains se requests accept karni hain
dj_database_url.config() Khud samajh jayega — local mein SQLite use karna hai, Render pe PostgreSQL
WhiteNoiseMiddleware Static files serve karega — SecurityMiddleware ke turant baad hona chahiye

3 .env File Banayein (Local Testing Ke Liye)

Root folder mein .env:

.env 
SECRET_KEY=aapki-purani-secret-key-yahan-daalein
DEBUG=True
Security Note: .env .gitignore mein already hai, is liye GitHub pe nahi jayegi — ✅ Good security practice!

Note: Purani SECRET_KEY settings.py mein already maujood hai, wahan se copy kar lein.

4 requirements.txt Update Karein

$ pip freeze > requirements.txt

5 build.sh File Banayein

Root folder mein build.sh:

build.sh 
#!/usr/bin/env bash
set -o errexit

pip install -r requirements.txt
python manage.py collectstatic --no-input
python manage.py migrate
Note: Is file ko executable banana parega:
chmod +x build.sh (Mac/Linux)

6 Changes Ko GitHub Pe Push Karein

$ git add .
$ git commit -m "Production settings for deployment"
$ git push

7 Render.com Pe Deploy Karein

1 render.com pe free account banayein (GitHub se sign up kar sakte hain — aasan hoga)
2 Dashboard mein "New +" → "Web Service"
3 Apni GitHub repository connect karein (task-manager)
4 Ye settings fill karein:
Build Command: ./build.sh
Start Command: gunicorn config.wsgi:application
5 Environment Variables section mein add karein:
SECRET_KEY koi bhi random lambi string
DEBUG False
6 Ek free PostgreSQL database bhi Render pe bana lein ("New +" → "PostgreSQL"), phir uska "Internal Database URL" copy karke web service ke environment variable DATABASE_URL mein daal dein
7 "Create Web Service" click karein
Done! Render khud build karega aur kuch minutes mein aapko ek live URL de dega, jaisa:

https://task-manager-xyz.onrender.com
Free Tier Note: Render ka service thodi der inactive rehne pe "sleep" ho jata hai (pehli request pe 30-50 second lag sakta hai load hone mein) — ye normal hai free plan mein. Recruiter ko batayein ke "free tier hosting" hai.

⚠️ Troubleshooting — Common Deployment Errors

Build Failed Check requirements.txt — ensure all packages are listed. Run pip freeze > requirements.txt again.
Module Not Found Make sure gunicorn, whitenoise, dj-database-url, psycopg2-binary, python-decouple are in requirements.txt
Database Error Check DATABASE_URL environment variable is set correctly. Render PostgreSQL URL starts with postgres://
Static Files Not Loading Make sure WhiteNoiseMiddleware is after SecurityMiddleware and STATIC_ROOT is set correctly
"DisallowedHost" Error Add .onrender.com to ALLOWED_HOSTS in settings.py
If you get any error: Exact error message paste kar dein — main turant fix karunga! 💪
