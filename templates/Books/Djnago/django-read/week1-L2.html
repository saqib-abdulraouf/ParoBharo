Django Project + Server Run

Create your first Django project and run the development server

3 Django Project Banana

Terminal mein (venv activate hona chahiye, (practice) dikhna chahiye), ye command chalayein:

Terminal / Command Prompt
django-admin startproject config .
Important: Aakhir mein wo . (dot) zaroor lagayein — is se project files seedha current folder mein banengi, ek extra nested folder nahi banega.

config project ka naam hai (aap chahen to koi aur naam bhi de sakte hain, lekin abhi ke liye isi ko follow karte hain).

Is command ke baad aapke folder mein ye structure banega:

django_practice/
practice/ (venv folder)
config/
__init__.py
settings.py
urls.py
asgi.py
wsgi.py
manage.py ← Django's command-line utility

4 Server Run Karke Check Karein

Terminal / Command Prompt
python manage.py runserver

Agar sab sahi hua to terminal mein kuch aisa dikhega:

$ Starting development server at http://127.0.0.1:8000/
✅ Success!

Browser mein http://127.0.0.1:8000/ open karein — Django ka welcome page (rocket wala) dikhna chahiye! 🚀

Pro Tip: Server chalte rahega jab tak aap Ctrl + C nahi dabaate. Har change ke baad server automatically reload hota hai (auto-reload) — isliye aap code edit karte rahein aur browser refresh karke dekh sakte hain!
