4 on_delete Ke Options

Jab related object (Category) delete ho, Django ko pata hona chahiye Task ka kya karna hai:

Option Kya karta hai
CASCADE Category delete hone par uske saare Tasks bhi delete ho jayenge
PROTECT Category delete nahi hone dega jab tak uske Tasks hain
SET_NULL Category delete ho, to Task ka category field NULL ho jayega (isme null=True hona zaroori hai)
SET_DEFAULT Ek default value set ho jayegi
Real-world Tip: Real projects mein SET_NULL bhi kaafi use hota hai (data loss avoid karne ke liye), lekin CASCADE sabse common hai.

5 ManyToMany Relationship — Tags

Ab ek Tag model banate hain. Ek Task ke multiple tags ho sakte hain, aur ek Tag multiple Tasks pe laga ho sakta hai — ye classic Many-to-Many hai.

tasks/models.py ko update karein:

tasks/models.py 
from django.db import models

class Category(models.Model):
    name = models.CharField(max_length=100)

    def __str__(self):
        return self.name


class Tag(models.Model):
    name = models.CharField(max_length=50)

    def __str__(self):
        return self.name


class Task(models.Model):
    title = models.CharField(max_length=200)
    description = models.TextField(blank=True)
    completed = models.BooleanField(default=False)
    created_at = models.DateTimeField(auto_now_add=True)
    category = models.ForeignKey(
        Category,
        on_delete=models.CASCADE,
        related_name='tasks',
        null=True,
        blank=True
    )
    tags = models.ManyToManyField(Tag, related_name='tasks', blank=True)

    def __str__(self):
        return self.title
ManyToManyField(Tag, ...) Task aur Tag ke beech Many-to-Many relationship
related_name='tasks' Tag se uske Tasks access kar sakte hain: tag.tasks.all()
blank=True Tags dena optional hai
Note: ManyToManyField mein on_delete nahi likhna padta — Django khud ek beech ki (junction) table bana leta hai.

8 Django Shell — ORM Queries

Django Shell Kya Hai?
Django ek interactive Python shell deta hai jahan aap apne models ko live test kar sakte hain — bina koi view/browser ke.

Terminal mein chalayein:
python manage.py shell

Step 1: Models Import Karein

>>> from tasks.models import Task, Category, Tag

Step 2: CREATE — Naya Data Banana

Django Shell 
# Category banayein
cat = Category.objects.create(name="Work")

# Task banayein us category ke sath
task1 = Task.objects.create(title="Learn Django ORM", category=cat)

# Tag banayein
tag1 = Tag.objects.create(name="Urgent")

# Task mein tag add karein (ManyToMany isliye alag tareeqe se add hota hai)
task1.tags.add(tag1)

Step 3: READ — Data Nikalna

Django Shell 
# Saare tasks
Task.objects.all()

# Sirf ek task (pehla wala)
Task.objects.first()

# ID se dhundna
Task.objects.get(id=1)

# Filter — sirf completed tasks
Task.objects.filter(completed=False)

# Ek category ke saare tasks (related_name use ho raha hai)
cat.tasks.all()

Step 4: UPDATE — Data Change Karna

Django Shell 
task = Task.objects.get(id=1)
task.completed = True
task.save()   # save() bhoolna nahi — warna change hoga hi nahi

Step 5: DELETE — Data Hatana

Django Shell 
task = Task.objects.get(id=1)
task.delete()
Important: Ye sab commands ek ek karke shell mein chalayein aur dekhein output kya aata hai. Ye exact wahi operations hain jo hum aage Views mein automate karenge (yehi CRUD ka core hai — Create, Read, Update, Delete).

9 Admin Panel Customize Karna

Admin Panel Customization: Abhi tak admin panel bilkul basic hai (sirf naam dikhta hai). Real projects mein isse professional aur useful banaya jata hai.

Step 1: ModelAdmin Class Banayein

tasks/admin.py ko update karein:

tasks/admin.py 
from django.contrib import admin
from .models import Task, Category, Tag

class TaskAdmin(admin.ModelAdmin):
    list_display = ('title', 'category', 'completed', 'created_at')
    list_filter = ('completed', 'category')
    search_fields = ('title', 'description')
    list_editable = ('completed',)

admin.site.register(Task, TaskAdmin)
admin.site.register(Category)
admin.site.register(Tag)

Har Cheez Samjhein:

list_display admin list page pe ye columns dikhenge (sirf naam nahi, poori info)
list_filter right side mein filter sidebar aayega (jaise sirf "completed" tasks dekhna)
search_fields top pe search bar aa jayega
list_editable is field ko list page pe hi edit kar sakte hain (task open kiye bina)
Note: list_editable mein wo field list_display mein first position pe nahi honi chahiye — warna Django error dega.

Step 2: Server Restart Karke Dekhein

$ python manage.py runserver

http://127.0.0.1:8000/admin/ pe jayein → Tasks pe click karein.
