Django ORM (queries likhna)

Learn to query your database using Python code — no SQL needed!

Django ORM ki practice karte hain (database ko Python code se query karna) — ye samajhna zaroori hai kyunke aage CRUD views mein yehi use hoga. Phir seedha CRUD Views pe chalenge, jo aapka asli goal hai.

21 Django Shell Mein ORM Try Karein

Terminal mein (venv active hona chahiye):

$ python manage.py shell
Samjhein: Ye ek interactive Python shell khol dega jahan aap directly database se baat kar sakte hain.

Ye commands ek-ek karke try karein:

Django Shell (Python)
from tasks.models import Task

# Naya task banana
Task.objects.create(title="Learn Django", description="Complete CRUD project")

# Sab tasks dekhna
Task.objects.all()

# Ek specific task dhundna
Task.objects.get(id=1)

# Task update karna
task = Task.objects.get(id=1)
task.completed = True
task.save()

# Task delete karna
task.delete()

# Shell se bahar aane ke liye:
exit()
>>> from tasks.models import Task
>>> Task.objects.create(title="Learn Django", description="Complete CRUD project")
<Task: Learn Django>

>>> Task.objects.all()
<QuerySet [<Task: Learn Django>]>

>>> Task.objects.get(id=1)
<Task: Learn Django>

>>> task = Task.objects.get(id=1)
>>> task.completed = True
>>> task.save()
✅ Task updated successfully!

>>> task.delete()
✅ Task deleted successfully!

ORM Methods — Summary

Method Purpose Example
.create() Naya record create karna Task.objects.create(title="...")
.all() Sab records fetch karna Task.objects.all()
.get() Ek specific record dhundna (ID ke through) Task.objects.get(id=1)
.save() Record update karna task.completed = True; task.save()
.delete() Record delete karna task.delete()
Key Takeaway: objects.create(), .all(), .get(), .save(), .delete() — ye sab ORM methods hain.

Bilkul yehi methods hum apni CRUD views mein use karenge, bas web browser se.
✅ Summary — What We Learned
