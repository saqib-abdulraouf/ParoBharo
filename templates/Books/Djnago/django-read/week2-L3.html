Full CRUD Implementation

Create, Read, Update, Delete — Complete Task Manager from browser
{% verbatim %}

CRUD functionality apni website pe (browser se) implement karna. Ye 4 parts mein hoga: Create, Read, Update, Delete.

Operation View Function URL Pattern Template
READ task_list / task_list.html
CREATE task_create /create/ task_form.html
UPDATE task_update /<id>/update/ task_form.html
DELETE task_delete /<id>/delete/ task_confirm_delete.html

22 List View (Read — Sab Tasks Dikhana)

tasks/views.py mein home function ko update karein:

tasks/views.py
from django.shortcuts import render, redirect, get_object_or_404
from .models import Task

def task_list(request):
    tasks = Task.objects.all()
    return render(request, 'tasks/task_list.html', {'tasks': tasks})

tasks/templates/tasks/task_list.html banayein:

tasks/templates/tasks/task_list.html
<!DOCTYPE html>
<html>
<head>
    <title>Task Manager</title>
</head>
<body>
    <h1>My Tasks</h1>
    <a href="{% url 'task_create' %}">+ Add New Task</a>
    <ul>
        {% for task in tasks %}
            <li>
                {{ task.title }} - {% if task.completed %}✅{% else %}❌{% endif %}
                <a href="{% url 'task_update' task.id %}">Edit</a>
                <a href="{% url 'task_delete' task.id %}">Delete</a>
            </li>
        {% empty %}
            <li>Koi task nahi hai abhi.</li>
        {% endfor %}
    </ul>
</body>
</html>
Samjhein: {% for %} template mein Python jaisa loop hai. {% url 'name' %} URL ko naam se generate karta hai (hardcode nahi karna padta).

23 Create View

tasks/views.py mein add karein:

tasks/views.py
def task_create(request):
    if request.method == 'POST':
        title = request.POST.get('title')
        description = request.POST.get('description')
        Task.objects.create(title=title, description=description)
        return redirect('task_list')
    return render(request, 'tasks/task_form.html')

tasks/templates/tasks/task_form.html banayein:

tasks/templates/tasks/task_form.html
<!DOCTYPE html>
<html>
<head>
    <title>Add Task</title>
</head>
<body>
    <h1>Add New Task</h1>
    <form method="POST">
        {% csrf_token %}
        <label>Title:</label><br>
        <input type="text" name="title" required><br>
        <label>Description:</label><br>
        <textarea name="description"></textarea><br>
        <button type="submit">Save</button>
    </form>
</body>
</html>
Samjhein: {% csrf_token %} Django ka security feature hai — har form mein zaroori hai warna error aayega.

request.method == 'POST' check karta hai form submit hua ya sirf page load hui.

24 Update View

tasks/views.py
def task_update(request, pk):
    task = get_object_or_404(Task, pk=pk)
    if request.method == 'POST':
        task.title = request.POST.get('title')
        task.description = request.POST.get('description')
        task.save()
        return redirect('task_list')
    return render(request, 'tasks/task_form.html', {'task': task})

task_form.html ko thoda update karein taake edit ke waqt purani values bhi dikhein:

tasks/templates/tasks/task_form.html (Updated)
<input type="text" name="title" value="{{ task.title|default:'' }}" required><br>
<label>Description:</label><br>
<textarea name="description">{{ task.description|default:'' }}</textarea><br>

25 Delete View

tasks/views.py
def task_delete(request, pk):
    task = get_object_or_404(Task, pk=pk)
    if request.method == 'POST':
        task.delete()
        return redirect('task_list')
    return render(request, 'tasks/task_confirm_delete.html', {'task': task})

tasks/templates/tasks/task_confirm_delete.html:

tasks/templates/tasks/task_confirm_delete.html
<!DOCTYPE html>
<html>
<body>
    <h1>Delete "{{ task.title }}"?</h1>
    <form method="POST">
        {% csrf_token %}
        <button type="submit">Yes, Delete</button>
        <a href="{% url 'task_list' %}">Cancel</a>
    </form>
</body>
</html>

26 Sab URLs Connect Karein

tasks/urls.py ko replace karein:

tasks/urls.py
from django.urls import path
from . import views

urlpatterns = [
    path('', views.task_list, name='task_list'),
    path('create/', views.task_create, name='task_create'),
    path('<int:pk>/update/', views.task_update, name='task_update'),
    path('<int:pk>/delete/', views.task_delete, name='task_delete'),
]
