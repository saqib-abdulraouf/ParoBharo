Part 1: User Authentication (Login/Signup)

Real apps mein har user apna alag data dekhta hai. Hum Django ka built-in authentication system use karenge.

1 Task Model Mein User Add Karein

tasks/models.py mein:

tasks/models.py 
from django.db import models
from django.contrib.auth.models import User

class Task(models.Model):
    title = models.CharField(max_length=200)
    description = models.TextField(blank=True)
    completed = models.BooleanField(default=False)
    created_at = models.DateTimeField(auto_now_add=True)
    category = models.ForeignKey(
        Category, 
        on_delete=models.CASCADE, 
        related_name='tasks', 
        null=True, 
        blank=True
    )
    tags = models.ManyToManyField(Tag, related_name='tasks', blank=True)
    user = models.ForeignKey(
        User, 
        on_delete=models.CASCADE, 
        related_name='tasks', 
        null=True, 
        blank=True
    )

    def __str__(self):
        return self.title
from django.contrib.auth.models import User Django ka built-in User model import karna
user = models.ForeignKey(User, ...) Har task ab ek user se link hoga
related_name='tasks' User se uske tasks access kar sakte hain: user.tasks.all()
null=True, blank=True Purane tasks ke liye optional (baad mein migrations handle karenge)

Part 2: Signup Functionality

Great! Ab Signup banate hain — Django built-in signup nahi deta, ye khud banani padti hai.

Step 1: Signup View Banayein

tasks/views.py mein add karein:

tasks/views.py 
from django.contrib.auth.forms import UserCreationForm

def signup(request):
    if request.method == 'POST':
        form = UserCreationForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect('login')
    else:
        form = UserCreationForm()
    return render(request, 'registration/signup.html', {'form': form})
UserCreationForm Django ka built-in form hai — username, password aur password confirmation khud handle karta hai

Part 3: Views Protect Karna + Sirf Apne Tasks Dikhana

Security Issue: Abhi koi bhi (bina login ke) task add/edit/delete kar sakta hai — isko fix karte hain.

Step 4: Login Required Banayein + User-Specific Data

tasks/views.py ko update karein:

tasks/views.py — Updated CBVs 
from django.contrib.auth.mixins import LoginRequiredMixin

class TaskListView(LoginRequiredMixin, ListView):
    model = Task
    template_name = 'tasks/task_list.html'
    context_object_name = 'tasks'

    def get_queryset(self):
        return Task.objects.filter(user=self.request.user)


class TaskCreateView(LoginRequiredMixin, CreateView):
    model = Task
    form_class = TaskForm
    template_name = 'tasks/task_form.html'
    success_url = reverse_lazy('task_list')

    def form_valid(self, form):
        form.instance.user = self.request.user
        return super().form_valid(form)


class TaskUpdateView(LoginRequiredMixin, UpdateView):
    model = Task
    form_class = TaskForm
    template_name = 'tasks/task_form.html'
    success_url = reverse_lazy('task_list')


class TaskDeleteView(LoginRequiredMixin, DeleteView):
    model = Task
    template_name = 'tasks/task_confirm_delete.html'
    success_url = reverse_lazy('task_list')
LoginRequiredMixin agar user login nahi hai, to automatically login page pe redirect kar dega
get_queryset() ye override kar ke sirf current logged-in user ke tasks dikhate hain, sabke nahi
form_valid() jab naya task banayein, uska user field automatically current user se set ho jata hai
Security Note: TaskUpdateView aur TaskDeleteView mein bhi LoginRequiredMixin laga diya — ab koi bhi bina login ke task edit/delete nahi kar sakta.

  • signup/ URL add kiya

  • get_queryset() override kiya (sirf apne tasks)
